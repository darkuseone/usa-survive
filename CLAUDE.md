# USA Survive (канал «Paper Survivors») — инструкция для Claude Code

Файл загружается автоматически. Канал **на английском для аудитории США**: выживание — зомби-апокалипсис, ядерный удар, бункеры, катастрофы, «что делать, если…». Формат — **длинные горизонтальные мультики 7–8 минут, 1920×1080, 24 к/с**. Рисуются **кодом** (canvas + JS) в стиле **«Аппликация»**: бумажная вырезка в духе ранних «Южного парка» + коллаж. Рендер — HyperFrames.

Стиль, движок и звук перенесены из проекта владельца «Том и Никита» (`darkuseone/cartoon-claude`, вертикальные Shorts на русском), где они отработаны на 9 сериях. **Персонажи, темы, тексты и юмор того канала здесь не используются** — здесь свои постоянные герои и свой голос канала. Из того проекта берём только визуальное качество и технологию.

## Окружение (новый контейнер)
```bash
bash tools/setup.sh      # .venv (numpy, scipy, pyloudnorm, faster-whisper) + Rhubarb + npm + проверка шрифтов, Chromium, ключа
```
- Ключ озвучки — секрет окружения `ELEVENLABS_API_KEY`. **Никогда не печатать ключи.** Голоса владельца в ElevenLabs (NIKITA, NIKITA2, Cartman и др.) **не трогать** — не удалять и не менять.
- Генеративные картинки и видео (xAI, Midjourney, Sora и т. п.) **не использовать**: всё рисуется кодом. Это решение владельца — генеративный вид он называл «нейрослоп».

## Конвейер (подробно — скилл `longform-episode`)
```bash
mkdir -p episodes/e01_<слово>                               # script.json (англ.), episode.json, set.js, scenes.js, sound.json — из episodes/_template
python3 pipeline/tts.py episodes/e01_<слово>                # ElevenLabs → vo/<ключ>.mp3 (готовые пропускает)
.venv/bin/python -I pipeline/transcribe.py episodes/e01_<слово>/vo/*.mp3
.venv/bin/python pipeline/voice_v2.py episodes/e01_<слово>  # → out/voice.wav + out/timeline.json (слова, виземы, выравнивание громкости)
python3 pipeline/words.py episodes/e01_<слово>              # индексы слов для CUE
tools/make.sh e01_<слово> snap 1,5,12,…                     # контакт-лист build/<эп>/snaps/sheet.jpg — СМОТРЕТЬ (Read) и править
tools/make.sh e01_<слово> sound                             # звук, печатает LU музыки и шумов
tools/make.sh e01_<слово> all e01_<слово>                   # рендер по частям по 60 с (в фоне!), склейка → out/<имя>.mp4 + _sheet.jpg + .srt
tools/make.sh e01_<слово> thumb e01_<слово> <сек>           # обложка → out/<имя>_thumb.png
```
- Рендер ≈ 15 мин на минуту ролика (4 воркера): эпизод 8 мин ≈ 2 ч. Запускать `run_in_background`, не опрашивать в цикле. Готовые части лежат в `build/<эп>/parts/` и при повторном запуске пропускаются: после правки одной сцены удалить только её часть.
- Готовое видео > 100 МБ в git **не коммитить** (лимит GitHub): отправлять пользователю файлом, в git — `_sheet.jpg`, `.srt`, `_thumb.png`.

## Правила качества (не нарушать)
**Кадр**
- Стиль: бумажные детали `piece()` (фактура, ножничный край, тонкий тёмный контур), группы в `layer()` с мягкой тенью, «кипение» на двойках (`jig`), удары и ключевые слова — `ransom()`, факты — коллаж на пробке/картоне со скотчем и булавками.
- Смена плана каждые 3–6 с (длинный формат — спокойнее Shorts, но без статики дольше 8 с), вставка-коллаж на каждый факт/цифру, «ломка паттерна» каждые 30–60 с (новая локация, флешбэк, карта, схема).
- Новая декорация на каждую главу/локацию. Нет темноты «в ноль»: амбиент `lightmap` не темнее `#5a5e74`.
- Текст в плашках не вылезает: ширина `card()` ≥ символы × размер × 0,62 + 80, или `label()`.
- Жесты: поза руки `'point'` выше плеча читается как **средний палец** — указывать вбок/вниз (`[230, 190, 'point']`).
- Факты (радиация, вода, укрытие, медицина первой помощи) — только из официальных источников (FEMA / ready.gov, CDC, Red Cross, NRC, армейские наставления), источник — мелко на вставке. Опасные советы не давать.

**Звук**
- Голос: `voice_v2.py` выравнивает каждую реплику к −21 LUFS (ElevenLabs отдаёт реплики с разбросом до 10 дБ; на динамике телефона тихие тонут). Шёпот — `"gain": -4` у реплики.
- Мастер −15 LUFS (YouTube нормирует к −14), пик −1.2 dBFS. Музыка −16…−19 LU, шумы −11…−13 LU (строки отчёта `make.sh sound`).
- Только своя синтезированная музыка и шумы (никаких чужих треков — Content ID).

**Площадка** — YouTube (длинные 16:9). Субтитры — отдельным `.srt` (вшитые выключены: `EP.subs = false`). Шорты-нарезки 9:16 — тем же движком (`"size": [1080, 1920]`).

## Git
- Основная ветка — `main`, владелец просит пушить в неё.
- Коммитить: `episodes/<эп>/` (script, vo, out/timeline.json и voice.wav, сцены, sound.json), `out/*_sheet.jpg`, `.srt`, `_thumb.png`, `research/`. Не коммитить: `build/`, `node_modules/`, `.venv/`, `tools/bin/`, `out/*.mp4`.
- В коммитах и файлах репозитория не указывать идентификатор модели.
