# Персонажи «Аппликации»

## Герои канала «Paper Survivors» (утверждены владельцем)
- **Joe** — `joe(o)` в `engine/chars.js`: «каждый» — серое худи, **оранжевая светоотражающая жилетка** (`vest`, цветовой якорь на обложках), бини цвета морской волны (`hair: 'beanie'`), щетина. Рассказ идёт во втором лице («You…»): Joe = зритель. Не менять силуэт и цвета без владельца.
- **Зомби** — `zombie(o)`: `v` 0–2 (три палитры), ярко-зелёная кожа, тёмные круги у глаз, шрам, рваный подол (`zombieMarks`). **Кожа зомби всегда явно зелёная**: под красным/тёмным светом серо-коричневая кожа читается как живой человек другой расы — так нельзя (проверено на обложке теста). Для тёмных сцен с зомби — холодный сине-зелёный свет, красный только акцентом.
- Образец сцены — `episodes/t01_gas` (заправка ночью, 18 с, обложка DAY 1 | DAY 30).

## Что уже есть
- `engine/chars.js` → **`person(o)`** — заготовка человека: та же конструкция, что у Никиты (`reference/tom-nikita/chars.js`), но параметрическая. Её можно сразу ставить в кадр (см. `episodes/demo`).
- `reference/tom-nikita/chars.js` — исходные `tom()` (кот-«груша», сидит) и `nikita()`: **образцы построения**, которые можно читать и копировать по приёмам. Самих Тома и Никиту в этом канале **не использовать**.

## Как сделать постоянного героя
1. Придумать с владельцем: роль (эксперт-выживальщик / паникёр-новичок / собака / сосед-параноик…), силуэт (рост, ширина, головной убор), 3–4 цвета, одна узнаваемая деталь (каска, противогаз на поясе, рация, очки, рюкзак).
2. В `engine/chars.js` — функция героя поверх `person()`:
```js
const MAC = { pal: { top: '#6f7a3e', topD: '#535d2b', hair: '#3a2a20', pants: '#4a4238', skin: '#f2cfb4' }, hair: 'cap', capCol: '#c8402c', top: 'jacket', beard: 1 };
function mac(o) { person({ ...MAC, ...o }); if (o.radio) radioP(...); }   // аксессуар — после person() в том же layer, в точке кисти
```
3. Нужна принципиально новая форма (женская фигура, ребёнок, толстяк, военный в бронежилете, зомби, животное) — новая функция по образцу `person()`: тело (`personBody`), ноги (`personLegs`), руки (`personArms` + `hand`), голова (`personHead` + `hairdo`). Копировать и менять контрольные точки, а не писать с нуля. Зомби: серо-зелёная кожа, один глаз-овал больше, рваные края одежды (`edge: 2`), руки вперёд `[±60, 160, 'open']`, `legs: 'run'` на половинной скорости.
4. Проверить дизайн: эпизод-лист с героем в 6 эмоциях и 3 позах → `tools/make.sh <эп> snap …` → показать владельцу контакт-лист. Только после «да» — в серии.

## Параметры `person(o)` (подробно — шапка `engine/chars.js`)
- Место: `x y` — центр головы, `s` масштаб (0.95 — стоит в общем плане 16:9), `flip`, `rot`, `lean`, `tilt`, `bob`.
- Вид: `pal {skin skinD hair hairL top topD pants shoe stub}`, `hair: 'shaggy'|'short'|'buzz'|'bald'|'cap'|'helmet'` (+ `capCol`), `beard`, `stubble`, `freckles`, `top: 'hoodie'|'jacket'|'tee'`, `badge`.
- Эмоция: `mood: ''|'shock'|'dumb'|'angry'|'sleepy'|'dread'|'sick'|'eww'`, `lid` (0–1 веко), `brow`/`browA`, `lk:[x,y]` (взгляд −1…1), `smile`, `m` — рот от `talk('<говорящий>', t)`.
- Руки: `arms: {l: [hx, hy, поза], r: [...]}` от центра головы; позы `'open'|'fist'|'point'|'phone'|'glass'`. Опущены `[-150, 300, 'open']`, у груди `[190, 110, 'fist']`, вверх `[150, -230, 'fist']`, в стороны `[±190, 40, 'open']`.
- Ноги: `legs: 'stand'|'run'|'sit'`. Сидя: сиденье ≈ `y + 345·s`, ноги до `y + 546·s`. Стоя: ступни на `y + 508·s`.

## Геометрия и мир
- Точка кисти в мире: `handW = a => [P.x + a[0] * P.s, P.y + a[1] * P.s]`; предмет в руке рисовать там же, в том же `layer`, **после** персонажа.
- Говорящий: `const tk = talk('mac', t); mac({ ...P, t, m: tk.m, bob: tk.bob, … })` — ключ говорящего = `speaker` в `script.json`.
- Взгляд друг на друга: левый `lk: [0.8, 0]`, правый `lk: [-0.8, 0]`. Эмоция меняется по слову: `ex(t, [[0, {...}], [CUE.word, {...}]])`.

## Грабли
- `'point'` с рукой выше плеча = средний палец. Указывать вбок/вниз.
- Персонаж «плавает» над полом → пересчитать `y = пол − 508·s`.
- Аксессуар за рукой → рисовать после `person()` в том же `layer`.
- Голова обрезана в крупном плане → камера `cam(P.x, P.y + 70…140, z ≤ 2.3)`.
