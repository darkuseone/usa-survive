# Эпизод 7–8 минут под ключ

Сначала (если не в контексте): `applique-style`, `applique-characters` (кто герои канала), `research/` (что залетает у образцов — скилл `channel-research`).

## 1. Тема и факты
- Тема — из `research/` (форматы и темы, которые у образцов набирают выше медианы канала) или от владельца. Формулировка-вопрос/ситуация: «What if a nuke hit your city?», «How long would you survive in a bunker?», «Day 1 of a zombie outbreak».
- Каждый факт/цифра — минимум 2 источника (FEMA / ready.gov, CDC, NRC, Red Cross, армейские наставления, рецензируемые статьи). Записать в `episodes/<эп>/facts.md`: факт → источники → как говорим в ролике (осторожно: «up to», «officials recommend»).
- Не давать опасных инструкций (оружие, взрывчатка, «народная» медицина). Мультяшное насилие — без крови, «за кадром».

## 2. Сценарий (`episodes/<эп>/script.json`, ~1000–1250 слов ≈ 7–8 мин при ~150 сл/мин)
- **Холодное начало 0:00–0:30**: последствие/катастрофа уже идёт + вопрос эпизода + обещание («by the end you'll know exactly what to do»). Название ransom-буквами в первом кадре.
- **5–7 глав по 50–80 с**, у каждой — своя мини-цель и поворот; между главами — «крючок» на следующую («But that's not the worst part…»). Каждые 30–60 с — смена локации/вставка-схема.
- Факты — через героев (эксперт объясняет, новичок ошибается/паникует) + вставка-коллаж на каждую цифру. Юмор — из характеров героев, не из унижения зрителя.
- Финал: вывод-чеклист (3–5 пунктов), шутка-развязка, призыв подписаться и карточка «next episode».
- Ключи реплик по порядку `a001…` (главы можно префиксом: `c1_01…`), поле `after` — пауза (0.1–0.2 обычно, 0.8–1.2 перед панчлайном), `gain` — для шёпота. Формат — скилл `applique-sound`.
- Ругательства — по решению владельца; по умолчанию без сильного мата (монетизация YouTube).

### Формула Paper Survivors (по research/competitors.md, эп. 1 — образец `episodes/e01_gas`)
- Название «Zombie Outbreak: 30 Days Locked Inside a <место, где был каждый американец>». Хук без приветствия: точное время + «You» + нарушение нормы (12–15 с), сразу «Day one. Twenty-nine to go.», затем обещание: «five problems… and one nearly kills you on Day 19» (открытая петля).
- 7–8 глав «Day N» по 40–75 с, нумерованные «Problem one…five», новая угроза каждые 60–90 с, цифра/факт каждые ~20 с, рефрен-правило («Rule of the night shift…») ≤ 5 раз, ложное облегчение → удар, вопрос зрителю в середине («What would you do?»), финал возвращается к хуку (3:07, колокольчик) + клиффхэнгер на Day 31 и CTA-вопрос в комменты.
- Хронометраж ≥ 8:00 (реклама в середине): паузы `after` 3,5 с под заставки глав, 5 с под титул, `tail` 6 с под концовку.

## 3. Озвучка и таймлайн
```bash
python3 pipeline/tts.py episodes/<эп>                                   # готовые реплики пропускает
LANG_STT=en .venv/bin/python -I pipeline/transcribe.py episodes/<эп>/vo/*.mp3 | tee build/<эп>_stt.txt   # теги не прочитаны, слова на месте
.venv/bin/python pipeline/voice_v2.py episodes/<эп> && python3 pipeline/words.py episodes/<эп> > build/<эп>_words.txt
```
Длинный вывод — в файл и `grep` по нужной реплике, не читать целиком.

## 4. Сцены (скилл `applique-engine`)
- `cp -r episodes/_template episodes/<эп>` (если ещё нет) — `episode.json` (timeline, size, libs, scripts), `set.js` (локации + вставки), `scenes.js` (общее), `ch01.js…` (главы: `SHOTS.push`, `Object.assign(SH, …)`).
- Рисовать главу за главой: глава → `tools/make.sh <эп> snap <8–16 моментов главы>` → Read `build/<эп>/snaps/sheet.jpg` → чек-лист `applique-style` → правки → переснять только изменённое (`rm -rf build/<эп>/snaps` перед снимком).
- Каждая локация — своя функция-декорация и свой свет; реквизит переиспользовать между главами можно, фон — нет.

### Переходы, HUD, главы (эп. 1)
- `SHOTS.push([t, 'имя', 'tear'|'whip'|'flash'|'dip'])` — переход в начале плана (функция `frame` переопределена в `set2.js`: рваная бумага, смазанная панорама, вспышка, уход в чёрное). Заставка главы — `chapterCard(t, c, день, 'НАЗВАНИЕ')`, титул — `titleCard`, концовка — `endCard`.
- Счётчик дней — `hudFrame` в `scenes.js` по списку `DAYS` (`[t, день, 'часы']`); планы с именем `…Ins`, `card…`, `title`, `end`, `flash…` — без счётчика.
- Помощники сцен: `SD` (магазин в темноте), `SL` (магазин со светом), `SE` (снаружи), `SB` (подсобка), `SQ` (морозилка); `J(t, {...})` — Joe с реквизитом (`lantern`, `clip`, `bottle`, `handset`, `pack`, `bag`), `Z` — зомби.
- Метки: `WW('ключ', /^слово/i)`; для звука в конце последней главы собирается `CUE` (метки глав с префиксами + `s_<план>`).

- **Третья версия эп. 1 (`fx3.js`, подключается после `scenes.js`)**: обёртки `SD/SB/SQ/SE` с дрейфом камеры и `o.pre` (реквизит за героем); на улице — `mist`, `ripples`, молния `LT.push(t)`; заставки `chapterCard`/`titleCard`/`endCard` с руками зомби `zHandsRow`; `cabClose` (окно пикапа); `coffeeStand`. Новые серии начинать с копии `set_store.js`, `set2.js`, `scenes.js`, `fx3.js`.

## 5. Звук — `episodes/<эп>/sound.json`, `tools/make.sh <эп> sound` (цели — скилл `applique-sound`).
- Длинный эпизод: `sound.json` генерировать скриптом (`episodes/e01_gas/mksound.py`: атмосфера по планам, звук на каждый переход, стинг+удар на заставки, музыка по главам). Длинные дорожки атмосферы — в `build/<эп>/amb/` (не в git), путь `wav:../../build/<эп>/amb/rain.wav`.
- **Во время рендера не трогать файлы эпизода**: части собираются по очереди перед рендером каждой. Обложку снимать отдельной мини-сценой (`episodes/e01_thumb`, `"duration": 1`).

## 6. Рендер (в фоне, ≈ 15 мин на минуту ролика)
```bash
tools/make.sh <эп> all <имя> > build/<эп>/make.log 2>&1; echo "exit $?" >> build/<эп>/make.log; grep -E "часть|exit|длительность" build/<эп>/make.log
```
- `run_in_background` (таймаут до 2 ч); если не уложилось — просто запустить снова: готовые части в `build/<эп>/parts/` пропускаются. Не опрашивать в цикле — ждать уведомления.
- Правка после рендера: изменить сцену → удалить только части, которые она задевает (имя файла = начало части в секундах) → `all`. Только звук — `mux`.
- Результат: `out/<имя>.mp4`, `out/<имя>_sheet.jpg` (24 кадра — Read и проверить), `out/<имя>.srt`.

## 7. Обложка и выкладка
- `tools/make.sh <эп> thumb <имя> <сек>` с отдельным планом-обложкой: крупный герой с сильной эмоцией, 2–3 слова ransom (не повторять название), одна яркая деталь (гриб взрыва, зомби-рука, гермодверь), контраст. Проверить на уменьшенной копии 320 px — читается?
- `publish/<эп>.txt`: название (≤ 70 знаков, интрига без лжи), описание (2–3 предложения + источники фактов + главы-таймкоды из `SHOTS`/реплик), теги, настройки (не для детей, если есть жестокость/ругань; категория Entertainment/Education).

## 8. Готово, когда
- Видео 7–8 мин, 1920×1080, 24 к/с, без JS-ошибок (`dbg`), контакт-лист без обрезанных плашек, факты сверены с `facts.md`.
- Звук в целях, голос ровный, `.srt` есть, обложка есть.
- Коммит в `main`: `episodes/<эп>/`, `out/<имя>_sheet.jpg`, `.srt`, `_thumb.png`, `publish/<эп>.txt` (сам `.mp4` > 100 МБ — не в git, отправить пользователю). `python3 tools/gen_refs.py`.

## Экономия токенов
- Не читать целиком `engine/*.js`, `reference/**` — есть `applique-engine/api.md` и `grep -n`.
- Один контакт-лист на главу, переснимать только изменённое. Склеивать шаги в один Bash через `&&`.
- Пока рендерится эпизод — писать тексты выкладки или следующую главу/эпизод (не рендерить два одновременно).
