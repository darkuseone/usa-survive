# toon3d — стиль B (основной стиль канала)

**Решение владельца 13.11.2026:** после сравнения S3 в двух версиях дальше всё — длинные и шортсы — только в стиле B («намного круче, дороже, сочнее»).
Аппликация (`engine/`, скиллы `applique-*`) — архив; из неё берём озвучку, звук, субтитры, факты (общие для обоих стилей).
**Пожелание владельца к B: больше непрерывной камеры** — камера скользит между объектами одним планом, склейка только когда меняется место или информация.

Образцы: `r3/src/videos/gas` (S3, заправка, жалюзи), `r3/src/videos/water` (S2, бойлер, подсобка, холодильная камера). Разбор исходного репозитория — `research/claude-animated-shorts.md`.

## Что где (`r3/`)
```
src/kit/        общее: shade.ts (двухтоновый свет), ink.ts (контур), lensblur.ts (DOF), grade.ts (грейд), cards.ts (карточки героев, LRU-кэш поз),
                toon.ts (рисунок героев: Pen, bodyFront/bodySide, выражения Expr, реквизит Prop, JOE, zombieFit, fx*),
                shots.ts (makeStory: планы -> кадр, сплайн-проезды, кики), short.tsx (makeShort: 3D + пост + надписи), overlay.tsx (надписи)
src/videos/gas/ world.ts (GasWorld: магазин, подсобка, холодильная камера, бойлер, навес, колонки, двор, толпа; состояние St), look.ts (свет-«луки»), paint.ts (текстуры)
src/videos/<эп>/ data.ts (из озвучки), story.ts (SHOTS + KICKS), <Эп>.tsx (надписи + makeShort)
src/Root.tsx    регистрация композиций (шортс 1080x1920 30 к/с)
scripts/        ep_data.py, campath.mjs + plan.py (план сверху), stills.mjs (кадры), collect_b.sh (сборка), cast_sheet.mjs (стенд героев)
```

## Маршрут шортса / эпизода
1. **Сценарий и голос** — как раньше: `episodes/<эп>/script.json` (англ., Arthur, `speed` 1.15 + `tempo` 1.1 для шортсов), `pipeline/tts.py` →
   `.venv/bin/python -I pipeline/transcribe.py …` → `.venv/bin/python pipeline/voice_v2.py episodes/<эп>` (→ `out/voice.wav`, `out/timeline.json`).
2. **Данные озвучки → TS:** `python3 r3/scripts/ep_data.py <эп> <папка>` → `r3/src/videos/<папка>/data.ts` (`DUR`, `LINES`, `WORDS`).
3. **Мир:** по возможности переиспользовать `GasWorld` и дополнять его (новые помещения — отдельный `buildXxx()` + поля в `St`); новый мир — свой `world.ts` по образцу.
4. **Раскадровка `story.ts`:** метки слов `Wd(key, /^слово/)`, планы `ShotDef`, кики `KICKS`, `makeStory(SHOTS, KICKS, DUR)` (см. «Камера»).
5. **План сверху (обязательно до кадров):**
   `cd r3 && node scripts/campath.mjs src/videos/<папка>/story.ts > out/<папка>_cam.json && ../.venv/bin/python scripts/plan.py out/<папка>_cam.json out/<папка>_plan.png [--shots a,b]`
   — стены, предметы, конус обзора камеры с учётом формата, герои (Joe — оранжевые квадраты, зомби — зелёные треугольники). Смотреть (Read): объект истории внутри конуса, камера не в стене.
   Прямоугольники мира заправки — список `GAS` в `plan.py`; новый предмет в мире → дописать туда.
6. **Черновые кадры** (~12 с на кадр вместо 40–80):
   `PROPS='{"post":{"ink":false,"lens":false,"bloom":false,"msaa":0,"shadow":512}}' node scripts/stills.mjs <Композиция> out/<папка>d/f_ <кадры> 0.35`
   по одному кадру на каждый смысловой бит → склеить в лист и смотреть. Чистовые 2–3 кадра — без `PROPS`, масштаб 0.5.
7. **Звук:** `episodes/<эп>/mksound.py` по образцу `episodes/s02b_water/mksound.py` (метки слов из `out/timeline.json`, Mixkit, лупы атмосферы),
   он же пишет заглушку `build/<эп>/cues.json`; затем `.venv/bin/python -I tools/sound_spec.py <эп>` → `build/<эп>/audio.wav` (−15 LUFS, пик −1.2).
8. **Рендер на GitHub Actions** (локально CPU ≈ 75 с/кадр — не вариант): `r3/render-request.json`
   `{ "composition": "<Композиция>", "frames": round(DUR*30), "jobs": 20, "concurrency": 2, "props": { "post": { "dpr": 1, "msaa": 4 } } }` → коммит и пуш
   в рабочую ветку запускает `.github/workflows/render-b.yml` (20 параллельных задач, ~25–40 мин), куски — в ветку `render-out`.
9. **Сборка:** `r3/scripts/collect_b.sh <эп> <имя>` → `out/<имя>.mp4` (склейка concat-фильтром — демуксер теряет кадры; звук из `build/<эп>/audio.wav`).
   Проверить: число кадров = frames, длительность; контакт-лист по секунде; сдать владельцу файлом (видео > 100 МБ в git не класть).

## Камера (главное в стиле) — по замерам образца @ricksclips3000 (`darkuseone/claude-animated-shorts/references/reports/motion.md`)
**Замечание владельца 13.11 к S2 v1:** «камера не непрерывная, где движется — скучно; каждые несколько секунд должно что-то происходить».
Длинные равномерные проплывы (`spline`) — это НЕ стиль образца. Образец (20 роликов, замер):
- **склеек почти нет** (0–1 на ролик); место меняется движением: камера идёт за героем/предметом, пролетает сквозь дверь/окно, кран,
  «хлыст» с размытием (7–25 кадров);
- **переезд каждые ~1,7 с** (6 на 10 с), длительность ~23 кадра (0,8 с), разгон и торможение симметричны (smootherstep);
  пик скорости медиана ~20 px/кадр при 1080 (p90 ~55), хлысты 70–140 px/кадр с сильным размытием;
- **между переездами — удержание с наездом** 0,15–0,35 %/кадр, стоячей камеры нет; удары — «кики» 6–7 кадров;
- **в каждом удержании герой что-то делает** (жест, шаг, предмет, смена эмоции за 0–3 кадра до слова).

Как это делать в `kit/shots.ts`:
- план с `beats: [{ t, d?, pos, look, fov, roll?, push? }]` — к моменту `t` камера приезжает за `d` с (по умолч. 0,8), потом держит кадр с наездом `push`;
  `pos`/`look` могут быть функциями времени (`tracking(герой)`) — камера ведёт героя;
- **размытие в движении** считается само (`F.blur`, `kit/dirblur.ts`) для переездов быстрее ~40 px/кадр — то есть для хлыстов и пролётов;
- хлыст: последний бит плана — быстрый поворот (d 0,3–0,35, небольшой угол), первый бит следующего — влёт с той же стороны (d 0,3–0,35);
- **проверки до кадров** (node, без рендера): скорость каждого переезда `STORY.speedAt(f)` (держать обычные ≤ ~100 px/кадр, хлысты ≤ ~600),
  нет перекрытия битов (старт следующего ≥ прибытия предыдущего — иначе скачок), нет NaN камеры;
- двери, через которые проходит герой/зомби, должны быть открыты настежь к этому моменту (иначе он проходит сквозь створку).
- Вертикальный кадр узкий (±13° по горизонтали при fov 46): два объекта в кадре — только на одной линии с камерой (через плечо),
  иначе — переезд/ведение от одного к другому.
- Свет — `look` (`backNight`, `coolerIn`, `warmIn`, `store`, `nightExt`; `mixLook` — переход, например день гаснет в ночь на одном кадре).

## Герои
- Карточки (плоские 2D-фигуры в 3D), рисуются кодом в `toon.ts`. **Joe** — `JOE` (оранжевая жилетка, бирюзовая шапка, щетина); зомби — `zombieFit(n)`.
- Спереди: `joe(x, y, z, { expr, look, blink, prop, headTilt, back, mode, phase, lift })`; сбоку (идёт/бежит) — `side: true, so: { mode: "march", phase, stride }`.
- Эмоции `Expr`: sleepy, nervous, fear, scream, relief, relief_open, resolve, shock, zom/zom2/zomO … Реквизит: `"bottle"`, `["handset", 0..1]`.
- Моргание `blink(t)`, дрожь `headTilt: k*sin(t*9)`, пар изо рта, царапанье (`pound`), руки зомби (`reach`).
- Новый жест/реквизит — в `toon.ts` (Prop + поза руки + рисунок), проверить стендом `node scripts/cast_sheet.mjs`.

## Надписи (overlay.tsx)
Субтитры по одному слову (y 1330, ключевые — жёлтые, список `HOT`), счётчик дня `DayTag` всегда в углу, карточка-факт `FactCard` с источником (FEMA / Ready.gov, CDC, Red Cross),
штампы `Word` на ударах, финальная карточка `EndCard` (вопрос + «FULL STORY ON MY CHANNEL» + стрелка). Крючок первых 3 с — две строки крупно.

## Грабли
- `stills.mjs` после смены story не пересобирать вручную — бандл каждый запуск свой; но держать одновременно только один процесс Chrome (иначе CPU захлёбывается).
- Склейка кусков — только `collect_b.sh` (concat-фильтр). Демуксер давал 1581 кадр из 1612.
- Толпа и карточки кэшируются (LRU в `cards.ts`): ключи поз квантовать (`phase` до 1/20), иначе кэш трэшится и рендер падает по таймауту.
- В `St` состояние мира — функция времени; скачки состояния (стеллаж «телепортирован») делать, когда предмет вне конуса камеры (проверить планом).
- Рендер на Actions: кусок без файла = упавшая задача (pipefail, 3 попытки). Падение «createLinearGradient … non-finite» = NaN в свете карточки,
  обычно из-за NaN камеры; проверка всех кадров без рендера — `campath.mjs` + поиск нечисловых значений (так нашли потерю крена в shots.ts 13.11).
  Дорендер только упавших диапазонов: `"ranges": [[a, b], …]` в render-request.json, сборка `KEEP=<старые куски> FRAMES=<n> collect_b.sh`.
- Генеративные картинки/видео не использовать. Mixkit-файлы в git не класть.
