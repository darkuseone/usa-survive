# Движок «Аппликации»

Справочник функций — `api.md` (`python3 tools/gen_refs.py`). Большие файлы целиком не читать: `grep -n "function имя" engine/*.js` + 5–10 строк.

## Как это работает
- `tools/mkpage.py <эп>` собирает `build/<эп>/film/`: `engine/*.js` + шрифты + `data.js` (`W, H, DUR, T0, PART, LINES` — реплики со словами и виземами из `timeline.json`) + `libs` и `scripts` из `episode.json` → `index.html` (шаблон `engine/page.html`).
- Страница рисует кадр функцией `draw(t)`: `frame(t)` выбирает план из `SHOTS` и зовёт `SH[имя](t, u)` (u — время от начала плана); поверх — `hudFrame(t)` (название, субтитры), `post()` (виньетка). Всё — чистая функция времени: одинаковый t → одинаковый кадр (случайность только `rng(зерно)`).
- HyperFrames (`npx hyperframes render`) проигрывает GSAP-таймлайн и снимает кадры 24 к/с. Длинный ролик режется на части по 60 с (`mkpage --part A B`, `T0` сдвигает время), части склеиваются `ffmpeg concat` без перекодирования.
- `tools/cues.cjs` выгружает `CUE`, `SC`, `DUR` со страницы → звук (`sound_spec.py`) ставится по тем же меткам, что и картинка.

## Эпизод (`episodes/<эп>/`)
- `episode.json`: `{"timeline": "episodes/<эп>/out/timeline.json", "size": [1920, 1080], "libs": ["engine/chars.js"], "scripts": ["set.js", "scenes.js", "ch01.js", …]}`; без озвучки — `"duration": сек`.
- `set.js` — декорации (функция на локацию) и вставки (функция на факт). Первая строка — комментарий-описание (попадает в api.md).
- `scenes.js` — `CUE`, `SHAKES`, `EP`, позиции героев, `scene()`, `SHOTS = []`, `SH = {}`. Главы `ch01.js…` дописывают: `SHOTS.push([t, 'имя'], …); Object.assign(SH, { имя(t, u) {…} })` — порядок файлов = порядок времени.

### Скелет
```js
const CUE = { boom: Wd('n03', 4), card1: Wd('n05', 0), alarm: LN.n09.start - 0.1 };   // Wd(ключ реплики, индекс слова) — индексы печатает pipeline/words.py
const SHAKES = [[CUE.boom, 0.6, 18]];                                                     // [время, длительность, сила px]
const EP = { title: ['NUCLEAR', 'BUNKER 101'], subs: false, hot: /^(radiation|shelter)/i };
const MP = { x: 640, y: 1000 - 508 * 0.95, s: 0.95 };
function scene(t, mo, ko, o = {}) { bunker(t, o); layer(() => { const tk = talk('mac', t); mac({ ...MP, t, m: tk.m, bob: tk.bob, ...mo }); }); …; bunkerLight(o.lit ?? 1, o.red ?? 0); }
const SHOTS = [[0, 'cold'], [LN.n02.start - 0.05, 'macA'], [CUE.card1 - 0.05, 'card1']];
const SH = { cold(t, u) { cam(960, 560, 1.05, 0, shakeAt(t)); scene(t, {...}, {...}); pop(); }, … };
```

## Камера и координаты
- `cam(cx, cy, z, rot, shake)` — центр мира в центр кадра, зум; **всегда закрывать `pop()`**. Проезд: `const [cx, cy, z] = ck(t, [[t0, x, y, z], [t1, x, y, z]])`.
- 16:9: общий `z 1.0–1.15`, средний `1.4–1.6`, крупный `1.9–2.3` (`cam(P.x, P.y + 100, 2.0)`). Пол ≈ `y 1000`.
- Вставка: `cam(W/2, H/2, 1)` + `slideIn(u, () => вставка(t, CUE))` — въезжает карточкой.
- Тряска: `SHAKES` + `cam(…, shakeAt(t))`. Наезд на слове: `z = t > CUE.x ? 2.3 : 2.0`.
- Надписи в экранных координатах (`hudFrame`, или внутри `cam(W/2, H/2, 1)`): заголовок y 150–300, ransom-удар `y ≈ H·0.17`, подпись вставки ≤ `H − 200`.

## Рецепты
- **Декорация**: фон `rectP` с `shade` (фактура: доски, плитка, бетон, обои) → крупный реквизит → передний план → `lightmap`. Образцы: `episodes/demo/set.js` (бункер), `reference/tom-nikita/episodes/ep03|ep07|ep08|ep09/set.js` (кухни, подъезд, ванная).
- **Вставка-факт**: `cork()`/`bg(цвет)` → `card()` + рисунок → цифра `ransom(…, { reveal: pr(t, t0, t0 + 0.3), pop: true })` → штамп/галочка → источник мелко `txt(…, 28–30)`.
- **Список шагов**: карточки появляются по CUE слов (`popK(t, t0, 0.3)`), номер красным, эмодзи `txt('🔦', …, { font: 'Noto Color Emoji' })`.
- **Карта/схема** (радиус взрыва, маршрут эвакуации): бумажная карта `rectP` с `shade` (улицы `stroke`), круги `ellP(…, 'rgba(0,0,0,0)', { raw: true, lw, lc })` расширяются по времени, подписи `label()`.
- **Свет**: тревога — красный `radial` с миганием `Math.abs(Math.sin(step(t, 12) * 4))`; вспышка взрыва — амбиент белый на 0.2 с + `SHAKES`; фонарик — `cone()`.
- **Петля/концовка**: последний план ведёт в «next episode» карточку или в первый кадр (для шортов).
- **Обложка**: отдельный план `'thumb'` в конце `SHOTS` (после `DUR` не попадёт в видео — ставить его в отдельный `SH.thumb` и снимать `make.sh <эп> thumb <имя> <сек>` с временно включённым планом) — крупный герой с эмоцией + 2–3 слова ransom + яркая деталь.

## Грабли
| Симптом | Решение |
|---|---|
| `Identifier 'X' has already been declared` | имя занято в engine (`P`, `SC`, `GROUPS`, `SUB`, `PC`…) → переименовать |
| Шрифт не применился | семейство с цифрами — в кавычках: `font: "'Courier 10 Pitch'"` |
| Текст вылез из плашки | `label()` или ширина `card` ≥ символы × размер × 0,62 + 80 |
| Сцена чёрная/каша | амбиент `lightmap` слишком тёмный → поднять |
| Предмет «за рукой» | рисовать после персонажа в том же `layer`, в точке кисти |
| Ошибка только в одной части рендера | `node tools/dbg.cjs build/<эп>/film` (все секунды) |
| `cues.cjs`: метки нет | в `sound.json` имя, которого нет в `CUE` |
| Перерендер одной сцены | удалить `build/<эп>/parts/<начало>.mp4` нужной части → `make.sh … all` |
| Рендер упал на середине | просто запустить `all` снова — готовые части пропускаются |
| `'point'` похож на средний палец | указывать вбок/вниз |
