# Образец стиля: «Том и Никита» (darkuseone/cartoon-claude)

Исходный проект, на котором отработана «Аппликация» (9 серий, вертикальные Shorts на русском). Здесь — **только для изучения приёмов**: как строятся персонажи, декорации, вставки, звук, раскадровка.

**Тома, Никиту, их темы, шутки и тексты в этом канале не использовать.**

- `chars.js` — исходные `tom()` и `nikita()`: конструкция персонажей (голова-овал, глаза-овалы, веки, брови-полоски, рты-замены, руки-трубки, причёска-«шапка»). Не подключать в эпизоды — имена `mouthAt/VIS/...` пересекаются с `engine/face.js`. Нужное — копировать приёмом в `engine/chars.js`.
- `props.js` — весь реквизит первых серий (коридор, лоток, кишечник, телевизор, полароид…): примеры декораций и вставок.
- `episodes/ep03|ep04|ep07|ep08|ep09/` — `set.js` (декорации, вставки), `scenes.js` (CUE, SHOTS, SH, планы, мат-панчлайн, петля), `sound.json`; `ep09/script.json` — формат сценария.
- `frames/*_sheet.jpg` — контакт-листы готовых серий: так должно выглядеть качество.
- `skills/` — скиллы того проекта (стиль, код сцен, монтаж Shorts, сценарий). Нужны для шортов 9:16 и как пример правил.

Координаты в этих файлах — для кадра 1080×1920 (вертикаль).
