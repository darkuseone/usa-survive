# Репозиторий claude-animated-shorts: разбор и что мы взяли (11.11.2026)

Форк владельца: `darkuseone/claude-animated-shorts`. Лицензия MIT, автор указан в `LICENSE` (копия лежит в `r3/src/kit/LICENSE`).

## Что это
Скилл для Claude и шаблон проекта для вертикальных мультиков «плоские 2D-человечки в 3D-мире».

Автор покадрово измерил 20 роликов того же канала-образца, что разбирали мы (@ricksclips3000). Отчёты лежат в `references/reports/`: контуры, свет, глубина, грейд, движение камеры.

**Стек:** Remotion 4 + `@remotion/three` + `@react-three/fiber` + `postprocessing`. Пример — 67-секундный ролик «The Bridge That Fell for a Song».

## Как устроено
- **Мир** — одна сцена three.js. Функция `update(кадр)` полностью определяет кадр по его номеру: Remotion рендерит кадры в параллельных вкладках в любом порядке.
- **Свет двухтоновый** (`shade.ts`). Цвет = альбедо × смесь «тень / свет». Освещённость берётся из карты теней одного «солнца» с мягким терминатором. Солнце привязано к камере плана: азимут отсчитывается от оси объектива.
- **Персонажи — плоские карточки** (`toon.ts`, `cardshade.ts`). Рисуются на Canvas2D из «бобов»: голова-суперэллипс, торс-боб, руки и ноги одной линией, контур толщиной «толсто-тонко» в сторону от света. Карточка получает тон сцены, светлую тень и градиент к солнцу.
- **Пост-обработка** (одна цепочка):
  1. чернильный контур мира (`ink.ts`): глубина + сгибы, персонажи и спрайты исключены;
  2. глубина резкости (`lensblur.ts`, тонкая линза);
  3. bloom только от HDR-источников (порог 1.0);
  4. тон-маппинг Neutral;
  5. грейд (`grade.ts`: кривая, насыщенность по зонам, оттенки, виньетка).
- **Грамматика камеры** (из `SKILL.md` и `story.ts`):
  - жёсткие склейки — только на больших скачках;
  - проезды 18–40 кадров с плавностью smootherstep;
  - каждый статичный план медленно «вползает» (0,15–0,35 % за кадр);
  - **ручной тряски нет**;
  - удары — «кики»: смещение меняет знак каждый кадр и затухает за 7 кадров;
  - крен 4–5°;
  - глубина резкости примерно на трети экранного времени.
- **Правило автора:** «никаких субтитров и надписей в кадре». У нас оно не действует: в версии B субтитры и штампы есть, как в версии A.

## Что взяли
1. **Версия B шортса S3 целиком собрана на этом движке:** `r3/`.
   - Модули репозитория без изменений лежат в `r3/src/kit/`: `shade`, `ink`, `lensblur`, `grade`, `cardshade`, `paint`.
   - В `toon.ts` добавлены:
     - **Joe**: бини с отворотом, оранжевый сигнальный жилет с полосами поверх серой толстовки, щетина;
     - **зомби**: серо-зелёная кожа, мутные глаза, рваные пятна, клочья волос, руки-«клешни», удары по жалюзи (вид со спины), шаг с вытянутыми руками (профиль);
     - **эмоции**: `sleepy`, `fear`, `scream`, `resolve`, `puff`, `zom`, `zom2`, `zomO`.
   - Мир заправки (`r3/src/videos/gas/world.ts`) — та же раскладка, что в `episodes/shorts/station3d.js`. Сделан на двухтоновых материалах с рисованными текстурами. Неон и лампы — HDR под bloom. Свет сквозь щели жалюзи — настоящая тень: у жалюзи прозрачные щели в материале глубины.
   - Раскадровка (`story.ts`) повторяет 23 плана версии A по меткам слов (`r3/scripts/gas_data.py`), но с грамматикой камеры репозитория.
2. **Для нашего движка (версия A и дальше)** — правила камеры:
   - убрать постоянную «ручную» тряску и заменить её «киками» на ударах;
   - во всех планах медленный наезд;
   - «хлыст»-смаз — только на 3D-пролётах, не на крупных планах с лицом. Уже сделано в `episodes/s03c_shutter/combo.js`.

## Запуск версии B
```bash
cd r3 && npm install                                    # один раз (node_modules не в git)
python3 scripts/gas_data.py                              # метки слов из версии A (нужен build/s03c_shutter/cues.json)
node scripts/cast_sheet.mjs                              # стенд персонажей -> out/gas/cast.png (секунды, без 3D)
node scripts/stills.mjs GasShort out/gas/f_ 114,435 0.5  # контрольные кадры (около 1 мин на кадр, программный WebGL)
# полный рендер и сведение со звуком версии A — scripts/render_gas.sh
```

## Цена и ограничения
- **Рендер медленнее нашего:** программный WebGL (SwiftShader), чернильный проход, размытие на 64 выборки, MSAA ×4. Время на кадр — в `r3/out/gas/render.log` после полного рендера.
- **Каждая новая локация — это код** (геометрия, текстуры, свет), как и у нас. Сцена заправки переиспользуется.
- **Лицензия Remotion:** бесплатно для частных лиц и компаний до 3 сотрудников. Для бо́льших компаний нужна платная лицензия. Шаблон репозитория — MIT.
